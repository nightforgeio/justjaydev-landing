# JustJayDev Landing

Personal landing page for @JustJayDev (builder / developer / gamer).
Live at: https://nightforgeio.github.io/justjaydev-landing/

## Features

- Bilingual EN + Hindi toggle
- Responsive design
- PWA manifest with icons
- Skip-to-content link for accessibility
- Back-to-top button
- Bilingual copy (EN + Hindi)

## Projects Shown

- Imperial Storm Esports team card (logo + team info)
- Placeholder contact links (GitHub, YouTube, Instagram, email)

## Development

Built with vanilla HTML/CSS/JS - no build tools required.
