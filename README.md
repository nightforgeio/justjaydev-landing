# JustJayDev Landing

Personal landing page for @JustJayDev (builder / developer / gamer).
Live at: https://nightforgeio.github.io/justjaydev-landing/

## Features

- Bilingual EN + Hindi toggle (one-tap language switch)
- Responsive, mobile-first layout
- PWA manifest with app icons and shortcuts
- Service worker with content-derived cache name (offline + fast reloads)
- Skip-to-content link for accessibility
- Visible focus states, reduced-motion support
- Floating back-to-top button
- Staggered scroll-reveal animations
- Interactive terminal easter egg
- SEO + Open Graph + JSON-LD structured data
